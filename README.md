# 🌷 봉일천고 진로진학상담 예약시스템

달력에서 날짜와 시간을 골라 학생·학부모가 상담을 신청하는 웹앱입니다.
선생님은 관리자 화면에서 상담 가능 시간을 열고 닫고, 컴시간 시간표 엑셀을 올려 수업 시간을 자동으로 뺄 수 있습니다.

## 주요 기능

**학생·학부모 화면 (`index.html`)**
- 달력에서 예약 가능한 날짜(남은 자리 수 표시) → 시간 선택 (기본 08~16시 매시 정각 시작, 한 번 50분)
- PC는 달력·시간 선택을 나란히 보는 2단 화면, 모바일은 한 줄 화면 + 하단 메뉴(상담 신청 / 내 예약 / 진로진학자료실)
- 신청 정보: 학번, 성명, 연락처, 학부모 참여 여부, 문의 내용(여러 개 선택 + 직접 입력), 교과 성적(선택), 모의고사 성적(선택)
- 개인정보 수집·이용 및 상담 시 조회 동의 (필수, 수집 항목·목적·보유 기간·거부권 안내)
- 신청 후 최종 화면에서 상담 일정·예약번호 확인, 캘린더(.ics) 추가, 인쇄/PDF 저장
- [내 예약 확인]: 학번+성명+연락처로 조회하고 직접 취소
- 같은 시간 중복 예약 차단, 학번당 예약 수 제한, 상담 몇 시간 전 예약 마감

**관리자 화면 (`admin.html`, 비밀번호 필요)**
- 예약 현황: 오늘/다가오는/지난/취소 예약, 상세 보기(성적 포함), 상담 메모, 완료·취소 처리, CSV(엑셀) 내려받기
- 상담 가능 시간: 주간 기본 시간표(칸 클릭·드래그로 열고 닫기) + 날짜별 조정(특정 날만 추가/차단)
- 시간표 가져오기: 컴시간 교사 시간표 엑셀(.xlsx/.xls/.csv) 업로드 → 수업 교시 자동 인식 → 교시별 시각과 겹치는 상담 칸을 닫아 주간 기본 시간에 적용
- 설정: 제목, 교사명, 학교/학급, 장소, 안내 문구, 예약 기간, 상담 요일, 시작/끝 시각, 상담 단위(분), 문의 항목, 보유 기간 문구, 비밀번호 변경
- 개인정보 파기: 선택한 날짜 이전 예약 일괄 삭제

> 기본 상담 칸은 08:00~08:50, 09:00~09:50 … 16:00~16:50 (하루 9칸)입니다. 첫/마지막 시작 시각, 시작 간격, 상담 길이는 [설정]에서 바꿀 수 있어요.
> 진로진학자료실 링크는 [설정 → 진로진학자료실 주소]에 넣으면 학생 화면 메뉴에 나타납니다.
> 관리자 화면 주소(`/admin.html`)는 학생 화면에 링크가 없으니 선생님만 따로 기억해 두세요.

## 설치 방법 A — 구글 스프레드시트 + GitHub Pages (무료, 권장)

서버 없이 운영할 수 있고, 예약 데이터는 **선생님 구글 계정의 스프레드시트**에만 저장됩니다.

### 1) 스프레드시트와 Apps Script 준비
1. 구글 드라이브에서 새 **스프레드시트**를 만듭니다. (이름 예: `상담예약 데이터`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 이 저장소의 [`gas/Code.gs`](gas/Code.gs) 내용을 붙여 넣습니다.
4. 왼쪽 **파일 +** → 스크립트 → 이름을 `Core` 로 만들고 [`gas/Core.gs`](gas/Core.gs) 내용을 붙여 넣습니다.
5. ⚙️ **프로젝트 설정**에서
   - 시간대를 `(GMT+09:00) 서울` 로 맞추고,
   - 맨 아래 **스크립트 속성 → 속성 추가**: 이름 `ADMIN_PASSWORD`, 값 `처음 쓸 관리자 비밀번호`
6. 편집기 위쪽 함수 목록에서 `setup` 을 고르고 ▶ **실행** → 권한 허용. 스프레드시트에 `예약` 시트가 생깁니다.

### 2) 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
2. 다음 사용자 인증 정보로 실행: **나**, 액세스 권한: **모든 사용자**
3. 배포 후 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> "모든 사용자"는 웹 앱 주소로 요청을 보낼 수 있다는 뜻일 뿐, 스프레드시트 자체는 공유되지 않습니다. 개인정보(연락처·성적)는 관리자 비밀번호가 있어야만 앱에서 볼 수 있어요.
> **관리자 비밀번호**는 따로 정해진 기본값이 없고, 위 1)-5에서 스크립트 속성 `ADMIN_PASSWORD`에 넣은 값이 처음 비밀번호입니다. 관리자 화면에서 바꾸면 그 뒤로는 바꾼 비밀번호만 통합니다.
> Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 새 버전**으로 다시 배포해야 반영됩니다.

### 3) 화면(GitHub Pages) 연결
1. [`docs/js/config.js`](docs/js/config.js) 의 `API_URL` 에 위 웹 앱 URL을 넣고 커밋합니다.
2. GitHub 저장소 **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / 폴더 `/docs` → Save
3. 잠시 뒤 `https://<아이디>.github.io/reserve/` 가 예약 화면, `…/reserve/admin.html` 이 관리자 화면입니다.
4. 관리자 화면에 1)-5에서 정한 비밀번호로 들어가 **[설정]에서 새 비밀번호로 바꿔 주세요.**

## 설치 방법 B — Node 서버 (학교 서버·개인 PC·클라우드)

Node.js 18 이상만 있으면 외부 패키지 없이 실행됩니다.

```bash
git clone https://github.com/2023swhs3rd-a11y/reserve.git
cd reserve
ADMIN_PASSWORD=처음비밀번호 npm start          # Windows PowerShell: $env:ADMIN_PASSWORD="처음비밀번호"; npm start
```

- 예약 화면: http://localhost:3000 , 관리자: http://localhost:3000/admin.html
- 데이터는 `data/db.json` 에 저장됩니다 (`DATA_FILE` 환경변수로 위치 변경, `PORT` 로 포트 변경).
- 이 방식에서는 `docs/js/config.js` 의 `API_URL` 을 빈 칸('')으로 두세요.
- 외부에 공개할 때는 반드시 HTTPS(리버스 프록시 등) 뒤에서 운영하고, `data/` 폴더를 백업하세요.

## 컴시간 시간표 가져오기

컴시간 프로그램(또는 컴시간 알리미)에서 **교사 시간표를 엑셀로 저장**한 파일을 관리자 화면 **[시간표 가져오기]** 에 올리면 됩니다. 인식하는 모양은 두 가지입니다.

| 형식 | 모양 |
|---|---|
| 교사 1명 격자형 | 머리행에 `월 화 수 목 금`, 왼쪽 열에 `1교시, 2교시…` (한 시트에 여러 교사가 위아래로 있어도 됨, 과목/반이 2줄이어도 됨) |
| 전체 교사 목록형 | 머리행에 요일(병합) + 아랫줄 `1 2 3…`, 또는 `월1 월2 …` 한 줄 머리행. 각 행이 교사 한 명 → 목록에서 교사 선택 |

- 칸에 글자가 있으면 수업으로 봅니다. 결과 표에서 칸을 눌러 고칠 수 있어요.
- **교시별 시각**(1교시 08:40~09:30 등)을 우리 학교 일과표에 맞춘 뒤 적용하세요. 수업과 조금이라도 겹치는 상담 칸이 닫힙니다.
- 엑셀이 없으면 화면의 **빈 시간표 양식(CSV)** 을 받아 직접 채워 올려도 됩니다.

**한계:** 컴시간 앱/알리미는 공식 API를 제공하지 않아 앱에서 직접 불러오는 기능은 넣지 않았습니다(비공식 방식은 주소·암호 규칙이 자주 바뀌어 쉽게 고장 납니다). 엑셀 저장 → 업로드가 가장 확실한 방법입니다. 파일 모양이 위 두 가지와 많이 다르면 인식하지 못할 수 있으니, 그럴 땐 [상담 가능 시간] 탭에서 직접 칸을 눌러 정해 주세요.

## 개인정보 보호

- 신청 전 수집 목적·항목·보유 기간·조회 동의·거부권을 안내하고 **동의해야만** 접수됩니다. 동의 일시가 함께 기록됩니다.
- 학생 화면과 공개 API는 다른 사람의 연락처·성적을 절대 돌려주지 않습니다. 조회는 학번+성명+연락처가 모두 맞아야 합니다.
- 관리자 기능은 비밀번호가 필요합니다. 비밀번호는 솔트+SHA-256 해시로 저장되며, Node 서버는 10회 실패 시 10분간 잠급니다.
- 관리자 로그인은 브라우저 탭을 닫으면 풀립니다(sessionStorage). 공용 PC에서는 [로그아웃]을 눌러 주세요.
- 보유 기간이 지나면 [예약 현황 → 개인정보 파기]로 삭제하세요. 학교의 개인정보 처리 지침이 있다면 그에 맞게 안내 문구(보유 기간)를 바꿔 주세요.

## 개발

```
docs/            화면(정적 파일, GitHub Pages 배포 폴더)
  index.html     학생·학부모 예약 화면
  admin.html     관리자 화면
  js/core.js     예약 규칙 핵심 로직 (Node 서버·Apps Script 공용)
  js/timetable.js 컴시간 엑셀 해석기
  vendor/        SheetJS(xlsx) — 엑셀 읽기용, Apache-2.0
gas/             Google Apps Script 백엔드 (Core.gs 는 자동 생성)
server.js        Node 백엔드
test/            테스트
```

```bash
npm test            # 테스트
npm run build:gas   # docs/js/core.js 수정 후 gas/Core.gs 다시 만들기
```
