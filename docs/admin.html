🧹 개인정보 파기

보유 기간이 지난 예약은 지워 주세요. 선택한 날짜 이전의 예약(취소 포함)이 모두 삭제되며 되돌릴 수 없어요.

📅 주간 기본 시간

매주 반복되는 상담 가능 시간이에요. 칸을 눌러 열고 닫을 수 있어요. (초록 = 상담 가능) 드래그하면 여러 칸을 한 번에 바꿀 수 있어요.

🗓️ 날짜별 조정

특정 날짜만 시간을 추가하거나 막고 싶을 때 날짜를 눌러 바꿔 주세요. (시험, 출장, 행사 등)

왼쪽 달력에서 날짜를 골라 주세요.

📥 컴시간 시간표 가져오기

  1. 컴시간 프로그램(또는 컴시간 알리미)에서 교사 시간표를 엑셀(.xlsx/.xls)로 저장해 주세요. 내 시간표 한 장이든, 전체 교사 시간표든 괜찮아요.
  2. 아래에 파일을 올리면 수업이 있는 교시를 찾아 보여 드려요.
  3. 교시별 시각을 확인한 뒤 [주간 기본 시간에 적용]을 누르면, 수업 시간을 뺀 나머지가 상담 가능 시간으로 채워져요.

엑셀 파일이 없다면 빈 시간표 양식(CSV)을 내려받아 수업이 있는 칸에 아무 글자나 적어 올려도 돼요. 컴시간 앱에서 직접 불러오는 기능은 공식 API가 없어 지원하지 않아요.

찾은 수업 시간 빨간 칸 = 수업 (눌러서 고칠 수 있어요)

⏰ 교시별 시각

우리 학교 일과표에 맞게 고쳐 주세요. 수업 시각과 겹치는 상담 칸은 자동으로 닫혀요.

✅ 적용하기

미리보기: 초록 = 상담 가능, 빨강 = 수업과 겹침

🏫 기본 정보

학생이 예약하거나 취소하면 이 주소로 메일이 가요. 비워 두면 알림을 보내지 않아요. (Google Apps Script로 운영할 때만 발송)

넣으면 학생 화면 메뉴와 완료 화면에 링크가 보여요. 비워 두면 숨겨져요.
